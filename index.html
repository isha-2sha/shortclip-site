ShortClip

A personal desktop tool for making and uploading short videos to my own YouTube channels.

ShortClip is a Windows desktop app that runs only on the owner's own computer. It turns short scripts into vertical videos (voice, images and subtitles) and uploads the finished videos to YouTube channels that the owner has connected.

YouTube API Services

ShortClip uses YouTube API Services to:

  • read the basic profile of a connected channel (channel ID, title, handle and thumbnail), so the app can show which channel a video will go to;
  • upload videos and their title, description and tags to that channel (videos.insert).

It does not read, analyze or change any other YouTube content, and it is not offered to other users.
